## Products

This glossary covers the following products only. Orchestration SDK terms are deferred.

Use the **Product** column abbreviations in each module table:

| Abbreviation | Product |
| --- | --- |
| **CA-GMA** | Custom Adapter (GMA SDK) |
| **CA-NG** | Custom Adapter (GMA Next-Gen SDK) |

When a keyword applies to more than one product, abbreviations are comma-separated (for example, `CA-GMA, CA-NG`).

Each section below is a **Module** as defined in the TapMind CA source sheet. Formulas stay inside the description when one applies.

> **Note:** Rows currently marked `CA-GMA, CA-NG` inherit the previous module-level scope. Narrow a row to `CA-GMA` or `CA-NG` alone when a keyword belongs to only one product.
