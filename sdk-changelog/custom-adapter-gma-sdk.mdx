## Version 3.0.2

AppLovin MAX iOS - Flutter

Package: `tapmind_ads_applovin_flutter: ^3.0.2`

Native SDK Version: `v3.0.1`

**Improvements**

- Send the mediation requested height and width to the backend.
- Added Product Key parameter to identify the product.
- Renamed adapter class from `com.tapmind.tech.TapMindMediationAdapterApplovin` to `com.tapmind.mediation.TapMindApplovinAdapter`.
- Added placement timeout to send no-fill to mediation after the configured backend timeout.
- Added ad refresh for Banner ads.
- Added logs at key points in the ad request and response flow for improved debugging and monitoring.
- Added Product Key parameter to the Impression APIs to identify the product.

**Fixed**

- Fixed support for multiple ad scenarios with proper thread management.
- Size optimization: use the platform configured size to fetch ad from GAM instead of mediation requested size.
